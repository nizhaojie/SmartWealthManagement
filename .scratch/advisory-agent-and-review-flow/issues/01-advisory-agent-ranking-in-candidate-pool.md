# 01 — 投顾助手 Agent 与候选池内排序

**What to build:** 理财顾问对一位客户发起方案生成，拿到一份产品推荐与资产配置建议，每款产品的排序依据可以拆开看（收益、风险、期限匹配度各自贡献多少），推荐理由引用了这位客户画像里的具体信息。

注意与客户侧筛选的分野：客户侧强制不排序（ADR-0005），顾问侧排序正是价值所在——差别在于送达对象是否经过持证人员审核。若实现时发现两边共用同一个排序函数，说明边界已经破了。

**Blocked by:** data-analysis-agent #03 — 结果解读与查询界面

**Status:** ready-for-agent

- [ ] 读取客户画像与持仓作为输入
- [ ] **只在候选池内排序，Agent 不重新做适当性判断**——提示词里不应出现适当性规则，那是已由结构保证的事
- [ ] 按收益、风险、期限匹配度加权打分
- [ ] **每项的贡献可被单独读出并展示**，不只有一个总分
- [ ] 推荐理由引用客户画像的具体信息
- [ ] 产出资产配置比例建议
- [ ] 可指定生成时的侧重（如更看重流动性或收益）
- [ ] 画像置信度低或已过期时给出警示
- [ ] 作为 LangGraph 运行时上的一份配置（ADR-0007）
