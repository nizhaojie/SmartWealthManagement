# 02 — AI 原稿落库与内容分类

**What to build:** Agent 生成的投顾内容以 AI 原稿的形式落库，此后不可修改——它是日后举证「审核是实质性的」的依据。内容是投顾内容还是事实性内容由调用的工具决定，而不是由模型自己声明。免责声明由模板附加，不依赖模型记得写。

**Blocked by:** 01 — 投顾助手 Agent 与候选池内排序

**Status:** ready-for-agent

- [ ] AI 原稿在生成时落库，**落库后不可修改**
- [ ] 内容分类由工具决定：调用了推荐类工具即产出投顾内容，只调用查询类工具则是事实性内容
- [ ] 投顾内容默认需经审核，不会自动送达客户
- [ ] **免责声明由模板附加**，是结构的一部分而非模型生成的文本
- [ ] 原稿记录生成时间、生成时使用的画像版本与候选池快照
- [ ] 客户侧接口读不到原稿
