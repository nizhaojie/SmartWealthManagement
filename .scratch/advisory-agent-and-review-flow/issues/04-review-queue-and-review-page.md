# 04 — 审核队列与审核界面

**What to build:** 理财顾问打开工作台看到待审队列，含每条内容的等待时长；点进一条进入审核页，左右并排看到 AI 原稿与自己的编辑版本，清楚自己改了什么；改完放行或填理由驳回。审核页有独立 URL，浏览器后退键回到队列。

**Blocked by:** 03 — 审核流：中断、放行驳回与并发加锁

**Status:** implemented

- [x] 队列消费客户提交的方案请求
- [x] **审核页有独立 URL**，可收藏可分享
- [x] **浏览器后退键从审核页回到队列**
- [x] 原稿与编辑版本并排渲染
- [x] 放行与驳回入口存在；驳回时理由必填，为空无法提交
