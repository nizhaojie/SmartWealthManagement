# 05 — 目标实际对比图与集中度提示

**What to build:** 顾问在画像面板看到一张目标配置与实际配置的对比图——「客户想要 30% 股票，实际持有 55%」，这个差值正是方案要解决的问题。同时系统基于持仓穿透的结果提示行业集中度风险，避免顾问推出一个让集中度更糟的方案。

**Blocked by:** 04 — 审核队列与审核界面

**Status:** ready-for-agent

- [ ] **用成对横向条形，不用双饼图**——两个饼图之间人眼无法比较扇区大小，条形可沿同一基线对齐直读差值（ADR-0006）
- [ ] **两组的类别顺序保持一致**，否则对比无从读起
- [ ] 目标配置取自画像，实际配置由持仓聚合得出，两者是不同的数据来源
- [ ] 差值本身有明确的视觉呈现
- [ ] 基于持仓穿透结果识别底层资产的行业集中度
- [ ] 集中度超过阈值时在方案生成时提示
- [ ] 复用既有图表封装与色板
- [ ] 空数据时渲染空状态
