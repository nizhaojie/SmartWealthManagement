# 04 — 助手气泡的内容面

**What to build:** 一轮的完整产物按固定次序落在助手气泡里：口径解读 → 结果表 → 可折叠 SQL → 元信息行；五种业务码各自成文案，截断与免责各有提示。**合规呈现面一件都不能少**——不能因为「变成聊天了」就降级成一句「出错了」。

**Blocked by:** 03 — 对话壳与输入区

**Status:** ready-for-agent

- [ ] 解读：`interpretation` 纯文本，原样呈现
- [ ] 结果表：`el-table`，列由 `columns` 决定，`rows` 拉链成对象；**不引入 ECharts**（后端不返回图表规格）
- [ ] SQL：默认折叠、可展开，`<pre data-testid="sql-block">` 属性保留，既有的护栏断言不破
- [ ] 元信息行贴底：`共 N 行 · 涉及 <views>`，右侧 `导出 CSV`（沿用 `csv.ts`，UTF-8 BOM 的客户端 Blob 下载）
- [ ] 截断提示：`truncated` 为真时渲染「结果超过行数上限，已截断：仅显示前 N 行，并非全量」
- [ ] 免责声明：`disclaimer` 非空时渲染（只有投顾内容才有；纯内部数据查询不带）
- [ ] **五种业务码各自成文案**，渲染为与正常回答同位置的警示块：1101 超出可查范围 / 1102 无法生成查询 / 1103 校验拒绝 / 1104 查询超时 / 1105 执行失败
- [ ] 新组件只服务数据分析；`AnalyticsResultView.vue` **原样不动**，继续服务风控问答
- [ ] 断言：五种业务码各自的文案都能渲染
- [ ] 断言：截断提示在 `truncated` 为真时渲染
- [ ] 断言：SQL 默认折叠、可展开；导出 CSV 可用；元信息行的行数与 `views` 正确

**实现落点：** `apps/internal/src/analytics/` 下新增气泡内的结果组件；`csv.ts`、`errorMessage`（`apps/internal/src/format.ts`）复用。`AnalyticsResultView.vue` 不进改动范围。

**验收：** 一次成功查询在气泡里同时看到解读、表格、可展开的 SQL 与行数口径；一次被拒绝的查询看到的是「查询未通过安全校验」而不是空表格。
