# 01 — 风险评测问卷与等级判定

**What to build:** 客户在客户端作答 16 道风险评测题，可以中途保存分几次答完，提交后立刻看到自己的风险承受等级与它的含义，以及这份评测的有效期。历次评测全部留存，顾问日后能看出他的风险偏好是否在变化。

**Blocked by:** internal-workbench-shell #03 — 检索试验页与阈值可视

**Status:** implemented

- [x] 16 道题覆盖收入、投资经验、风险承受力、投资目标四个维度，每题四个选项对应不同分值
- [x] 问卷可中途保存，重新进入时已答题目仍在
- [x] 总分映射到 C1–C5 五档，库中存 C1–C5，界面显示对应中文名
- [x] 每次评测写入评估记录表，**历次记录全部保留不覆盖**
- [x] 评测结果同步更新客户画像的等级与分值
- [x] 评测有有效期，客户能看到到期时间
- [x] 客户端问卷页与结果页，结果解释等级的含义
- [x] 客户看得到自己的等级结论与有效期，看不到置信度与研判过程
