# 02 — 画像标签、置信度、冲突记录与四维度研判

**What to build:** 系统为每位客户维护一份带置信度的画像：每个标签知道自己从哪来、有多可信、有多新鲜；标签被更新时旧值不消失而是留下冲突记录。四维度加权研判把这些信息综合成风险承受等级，四个维度各自的得分能被单独读出——顾问要能向客户解释结论是怎么来的。几条硬性门槛在打分之前就熔断。

**Blocked by:** 01 — 风险评测问卷与等级判定

**Status:** ready-for-agent

- [ ] 每个标签带来源与 0 到 1 的置信分
- [ ] 置信度计算是纯函数：来源初值、证据累积增益（有上限）、冲突惩罚、时间衰减，结果钳制在 0 到 1
- [ ] 置信度计算的时间基准由参数传入，不在内部读时钟（ADR-0011）
- [ ] 冲突处理：来源置信度高的覆盖低的；来源相同则新覆盖旧
- [ ] **冲突记录保留**，可查到该标签曾经是什么、何时被什么来源改掉
- [ ] 理财顾问的手工修正记为高置信来源，不被后续 AI 对话提取覆盖
- [ ] 手工修正必须填写理由
- [ ] 四维度加权：基础属性 25%、投资经验 25%、风险偏好 30%、行为异常 20%，总分映射到 C1–C5
- [ ] **四个维度各自的得分可被单独读出**，不只有一个总分
- [ ] 硬性门槛判断**先于**加权打分，命中即熔断不再计算等级
- [ ] 四类熔断各自生效：年龄小于 18、年龄大于 80、无收入且资产不足万元、评测过期
- [ ] 熔断结果与原因可传到界面
- [ ] 画像读取走 Cache-Aside；缓存不可用时直连数据库，恢复后回填
- [ ] 客户侧接口不返回置信度、四维得分与冲突记录
