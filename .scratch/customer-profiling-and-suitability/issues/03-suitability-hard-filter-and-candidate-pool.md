# 03 — 适当性硬过滤与候选池

**What to build:** 查询一位客户可选的产品时，越级产品**根本不出现在结果里**——不是查出来再过滤，不是列出来置灰，而是在数据访问层就被约束掉。过滤后剩下的集合即候选池，是后续投顾推荐的唯一输入范围。这是评分表里「适当性违规」那条红线的实现处。

**Blocked by:** 02 — 画像标签、置信度、冲突记录与四维度研判

**Status:** ready-for-agent

- [ ] 适当性规则一处定义、多处引用，不在两个地方各写一遍
- [ ] 匹配是序数比较：Cn 客户可持有 R1 至 Rn
- [ ] **过滤发生在检索层**，越级产品不进入结果集，不存在「查出来了但没展示」的中间状态
- [ ] **护栏测试：C1 客户的候选池里不出现 R2 及以上产品**
- [ ] C3 客户能拿到 R1–R3，拿不到 R4 与 R5
- [ ] 构造请求参数试图绕过等级约束时，服务端仍不返回越级产品
- [ ] 硬性门槛熔断的客户，其候选池受相应限制（无收入低资产仅 R1–R2）
- [ ] 评测过期客户的画像权限被冻结，无法取得候选池
- [ ] 每次适当性判定留下记录，可追溯当时依据的是哪一份评测
