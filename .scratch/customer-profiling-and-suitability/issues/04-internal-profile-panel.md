# 04 — 内部端客户画像面板

**What to build:** 理财顾问在工作台打开一位客户的画像，一屏看到他的风险承受等级、投资经验、资产规模、目标配置与产品偏好；每个标签旁边是它的置信度与来源，页面上标着这份画像的计算时间；四维度得分可以展开看，于是顾问能向客户解释等级是怎么来的。客户被硬性门槛熔断时，页面直接说明原因。

**Blocked by:** 03 — 适当性硬过滤与候选池

**Status:** ready-for-agent

- [x] 画像面板渲染各标签及其置信度与来源
- [x] 画像的计算时间可见，顾问知道数据的新鲜度
- [x] 四维度得分可展开查看
- [x] 历次风险评测记录可查看，能看出等级变化
- [x] 顾问可手工修正标签并填写理由，修正后置信度与来源随之变化
- [x] 标签冲突记录可查看
- [x] 熔断状态渲染原因说明而不是空白
- [x] 画像置信度低或已过期时有警示
- [x] 落在内部工作台既有外壳内，有独立路由
