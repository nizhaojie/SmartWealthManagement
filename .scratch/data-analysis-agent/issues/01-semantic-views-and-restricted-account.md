# 01 — 语义视图与受限执行账号

**What to build:** 建立一组只读的语义视图，覆盖客户概况、持仓分布、交易统计、产品要素等分析场景。视图里没有敏感字段，行级权限内建在视图定义中，执行查询用的数据库账号**只对视图有权限、对基础表无权限**。这是 ADR-0010 的地基——安全性从「嘱咐模型别查」变成「结构上取不到」。

**Blocked by:** product-screening-and-customer-assets #05 — 持仓穿透

**Status:** ready-for-agent

- [ ] 视图覆盖客户概况、持仓分布、交易统计、产品要素、预警统计等场景
- [ ] **敏感字段不出现在任何视图中**：身份证号、手机号、银行卡号、密码散列一律不进；真实姓名按脱敏规则出现
- [ ] **行级权限内建在视图定义中**，越权读取在 SQL 层不成立
- [ ] 口径固定：像「资产规模」这类字段在视图里有明确定义，不由调用方临时拼聚合
- [ ] **执行账号对基础表无权限**——这是本 ticket 最关键的一条，若执行账号仍能访问基础表，语义视图就只是一层建议
- [ ] 视图由迁移脚本定义，与表结构一同版本化
- [ ] 测试验证：用执行账号直接查询基础表被拒绝
- [ ] 测试验证：视图返回结果中不含身份证号、手机号、银行卡号
