# 02 — 查询生成、安全校验与执行

**What to build:** 员工用日常语言提一个数据问题，系统生成一条只作用于语义视图的只读查询，通过校验后执行并返回结果。任何写操作被拒绝；试图诱导模型越权取数时，视图与受限账号让它取不到。

**Blocked by:** 01 — 语义视图与受限执行账号

**Status:** ready-for-agent

- [ ] 按问题关键词只注入相关视图的定义，不注入全部，避免提示词随视图增多而膨胀
- [ ] 提供少量「问题 → 查询」示例，示例可配置而不必改代码
- [ ] **护栏测试：写类操作与结构变更一律被拒绝**——覆盖删除、更新、插入、结构变更、清空等
- [ ] **提示词注入式的提问不改变可访问的数据范围**（例如要求忽略先前指令）
- [ ] 试图访问视图外对象时执行失败或返回空，取不到基础表数据
- [ ] 结果行数有上限，超出时截断并在响应中带明确的截断标记
- [ ] 查询有超时上限
- [ ] 校验失败返回明确的业务错误码，不返回 500
- [ ] 每次查询留下永久记录：提问人、问题、生成的查询、返回行数
- [ ] 测试中 fake provider 可被配置为返回指定的恶意查询，以验证**校验层与视图层拦得住**，而不是验证模型乖
