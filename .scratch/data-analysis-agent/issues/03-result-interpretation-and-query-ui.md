# 03 — 结果解读与查询界面

**What to build:** 员工提问后拿到的不只是一张表格，还有一段说明这些数字意味着什么、按什么口径统计的自然语言解读。生成的查询语句默认折叠但可展开——他需要能判断系统有没有理解自己的问题。答不上来时明确说明是问题超出可查范围还是无法生成查询。

**Blocked by:** 02 — 查询生成、安全校验与执行

**Status:** implemented

- [x] 结果集与原始问题一起送入模型生成自然语言解读
- [x] **解读说明数据口径**——同一个「收益率」在不同口径下是不同的数字
- [x] 结果以表格呈现，与解读同时可见，不是只有表格
- [x] 生成的查询语句默认折叠、可展开
- [x] 截断提示在结果被截断时渲染
- [x] 答不上来时渲染原因（超出可查范围 / 无法生成查询）而非空表格
- [x] 多轮追问时上一轮问题进入上下文，「那上个季度呢」能被理解
- [x] 历史查询可查看与重用
- [x] 结果可导出
- [x] 界面提供示例问题，让员工知道这个工具能回答什么
- [x] 面向客户的报告类输出附免责声明；纯内部数据查询不附
- [x] 落在内部工作台既有外壳内，有独立路由
