# 03 — 两个身份域的登录与隔离

**What to build:** 客户在客户端登录，员工在内部工作台登录，两者的凭证互不通用——客户凭证打到任何内部接口一律被拒。这是身份域从概念变成结构的一步（ADR-0004），后续所有接口的权限都建立在它上面。

**Blocked by:** 02 — 数据库结构与测试数据

**Status:** implemented

- [x] 登录成功返回短时效访问凭证与刷新凭证
- [x] 密码以自适应哈希算法存储，库中不存明文也不存可逆密文
- [x] 登录失败的提示不区分「账号不存在」与「密码错误」
- [x] 客户凭证与员工凭证使用不同的受众标识，校验时受众不匹配一律拒绝
- [x] **护栏测试：客户凭证访问任一内部接口返回 401 或 403**
- [x] 未携带凭证访问任何业务接口被拒绝
- [x] 凭证过期后可用刷新凭证换取新的访问凭证
- [x] 两个前端应用各有自己的登录页，各自独立维持登录态
- [x] 前端在凭证失效时导向登录页，而不是把错误抛给用户
- [x] 客户可主动登出，登出后原凭证不再可用
