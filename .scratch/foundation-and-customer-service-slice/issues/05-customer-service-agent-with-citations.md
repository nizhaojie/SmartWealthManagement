# 05 — 智能客服 Agent 与带引用的回答

**What to build:** 客户提一个关于产品或政策的问题，拿到一个每个论断都挂着来源的回答；问一个知识库答不了的问题，拿到明确的「不知道」与人工渠道，而不是一个听起来可信的编造。连续追问时系统记得刚才聊过什么。

**Blocked by:** 04 — 知识入库、检索与 FAQ 导入

**Status:** ready-for-agent

- [ ] LangGraph 运行时建立，智能客服作为其上的一份配置（ADR-0007）
- [ ] 工具集内不存在任何推荐类能力
- [ ] 意图分为产品咨询、政策解读、FAQ、闲聊、转人工五类，前三类走检索，闲聊引导回业务，转人工返回固定话术
- [ ] **检索最高分低于阈值时直接返回兜底话术与人工渠道，且不发起模型调用**
- [ ] 引用是结构化数据，至少含文档标识与段落位置，不是回答文本里的字符串
- [ ] 模型输出的引用标识在本次检索结果中找不到对应时，该引用在返回前被剔除
- [ ] 短期记忆存于缓存，滑动过期，总 token 超预算时截断最旧消息
- [ ] 重新登录后上一次会话的上下文不可见
- [ ] 会话结束后完整流水写入归档表，写入前脱敏身份证号、手机号、真实姓名、银行卡号
- [ ] 工具调用记录随归档留存
- [ ] 每次调用留下审计级留痕：使用者、Agent、问题、最终答案、引用文档、内容分类
- [ ] fake provider 下回答结构完整、引用合法（它同时是演示兜底路径，ADR-0008）
