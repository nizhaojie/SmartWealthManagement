# 06 — 流式输出与客户端对话页

**What to build:** 客户在对话页提问，回答逐字出现；读到某句话时可以点开它的引用角标，看到来源文档与段落位置。这是第一刀的收口——完成后「登录 → 提问 → 流式回答 → 可点击引用」整条链路可演示。

**Blocked by:** 05 — 智能客服 Agent 与带引用的回答

**Status:** ready-for-agent

- [ ] 流式接口返回 text/event-stream，逐字推送
- [ ] 兜底判断、引用剔除、内容分类全部在开始推流之前完成，推流过程中不再改变回答性质
- [ ] 流的末尾包含完整回答与全部引用
- [ ] 对话页渲染多轮消息，长对话正常滚动
- [ ] 引用渲染为可点击角标，点击后来源信息可见
- [ ] 兜底回答渲染人工渠道，且不渲染任何引用角标
- [ ] 引用面板保留自有 DOM 结构与全部 ARIA 属性，组件库只提供外层容器（ADR-0009）
- [ ] 未登录访问对话页被导向登录页
- [ ] 流式过程中断开连接不产生未捕获异常
