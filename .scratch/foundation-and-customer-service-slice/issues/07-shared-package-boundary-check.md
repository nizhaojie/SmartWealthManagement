# 07 — 共享包业务语义构建期检查

**What to build:** 有人试图把内部业务概念放进共享包时，构建失败并指出问题。这道检查守的是 ADR-0003 的边界——共享包一旦承载业务语义，内部逻辑就会被打包进客户端产物，两个应用分开的意义随之消失。

**Blocked by:** 01 — 工程骨架与健康检查贯通

**Status:** ready-for-agent

- [ ] **护栏测试：共享包的依赖图中不得出现业务语义标识**
- [ ] 检查是构建流程的一步，失败即中断构建，不是一条可忽略的警告
- [ ] 检查有明确的判据说明什么算业务语义（风控规则字段、预警分级、审核流状态、画像权重等），什么不算（HTTP 客户端、主题令牌、格式化函数、图表壳）
- [ ] 失败时的报错指明是哪个标识越界
- [ ] 故意在共享包中引入一个业务语义标识，构建确实失败
