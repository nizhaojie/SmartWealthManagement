# 01 — 内部工作台外壳与角色导航

**What to build:** 员工登录内部工作台后看到一个完整的应用外壳：左侧导航按自己的角色显示可见模块，每个页面有独立 URL，浏览器前进后退正常工作，尚未实现的模块显示占位说明。任何角色、任何页面下都能登出。

**Blocked by:** foundation-and-customer-service-slice #07 — 共享包业务语义构建期检查

**Status:** ready-for-agent

- [ ] 使用真实路由，不用条件渲染切换界面——URL 随页面变化，可被收藏与分享
- [ ] 浏览器后退键能回到上一个页面
- [ ] 左侧导航项由「角色 → 可见模块」的声明式配置生成，新增模块是加配置项而非改导航组件
- [ ] 三个员工角色（理财顾问、风控专员、客户经理）登录后都看到完整外壳，各自的可见模块不同
- [ ] **登出入口在外壳层，任何角色、任何路由下都存在且可用**
- [ ] 顶部显示当前位置的面包屑
- [ ] 显示当前登录者的姓名与角色
- [ ] 尚未实现的模块渲染统一占位页，说明该模块的预期能力；占位页仍有导航、面包屑与登出
- [ ] 访问本角色无权访问的路由时被明确拒绝，而不是靠导航隐藏
- [ ] 凭证失效时导向登录页
- [ ] 后端接口独立做角色校验，绕过前端守卫拿不到数据
