# 02 — 知识库管理界面

**What to build:** 知识库维护者在界面上传一份产品手册，看到解析与入库进度，成功后它出现在文档列表里；删掉它时有确认提示，删完之后 Agent 再也不会引用它。不必再开 Swagger 拼请求体。

**Blocked by:** 01 — 内部工作台外壳与角色导航

**Status:** implemented

- [x] 上传支持 txt、md、docx，可选择知识类型（FAQ、产品、政策）
- [x] 上传是异步的：接口立即返回处理中状态，界面展示进度
- [x] 解析、分块、Embedding、入库四个阶段各自失败时，失败原因能传到界面
- [x] 文档列表展示知识类型、标题、来源文件、版本、状态、入库时间、分块数、过期时间
- [x] 列表可按知识类型与状态筛选
- [x] 删除有确认提示，确认后触发元数据、向量、原始文件三处联动
- [x] 删除后文档从列表消失且不再出现在检索结果中
- [x] 过期时间临近的文档在列表中有视觉标记
- [x] 上传不支持的格式时界面显示明确原因，不是一个泛化的失败提示
