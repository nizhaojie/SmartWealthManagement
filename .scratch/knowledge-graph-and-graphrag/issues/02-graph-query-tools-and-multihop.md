# 02 — 图谱查询工具与多跳场景

**What to build:** 顾问问「客户 A 和客户 B 有什么共同持仓」「张三的持仓集中在哪些行业」「这位基金经理还管着哪些产品」，系统沿关系走几跳给出准确答案。查询封装成工具，Agent 传实体标识而不是拼查询语句。

**Blocked by:** 01 — 图谱模型与幂等全量重建

**Status:** ready-for-agent

- [ ] 六个工具：客户持仓产品、产品所属行业、某风险等级的适配产品、客户持仓的行业分布、客户间共同持仓、基金经理管理的产品
- [ ] **Agent 不拼查询语句**——工具参数是实体标识，查询语句在工具内部固定
- [ ] 工具拒绝超出其参数契约的输入
- [ ] 三个多跳场景各自返回正确结果：持仓行业分布、客户间共同持仓、基金经理关联
- [ ] 图谱结构变化时只影响工具实现，不影响调用方
