# 04 — 图谱关系图界面

**What to build:** 顾问在工作台看到一位客户的持仓关系网络——持有哪些产品、属于哪些行业、由谁管理、在哪里形成了集中。点节点看要素，按关系类型过滤，集中度超阈值的行业有标记。

**Blocked by:** 03 — GraphRAG 融合排序与降级

**Status:** implemented

- [x] 用关系图渲染节点与连线
- [x] 四类节点各有区分的视觉编码（客户、产品、行业、基金经理）
- [x] **默认只展开到产品与行业两跳**，更深层级按需展开——一位客户的完整网络可能上百节点，全画出来是一团乱麻
- [x] 可按关系类型过滤，过滤改变渲染的连线集合
- [x] 点击节点显示其要素，不必切换页面
- [x] 集中度超阈值的行业节点有视觉标记
- [x] 显示图谱数据的同步时间，顾问知道自己看的是什么时点的结构
- [x] 图谱数据为空时渲染空状态而非空白画布
- [x] 复用既有图表封装与色板
- [x] 落在内部工作台既有外壳内
