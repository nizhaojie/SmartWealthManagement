# 01 — 三层记忆边界与归档脱敏

**What to build:** 把三层记忆的分工落实并补齐缺口：短期记忆是当前会话的消息，中期记忆是画像与工单状态，长期记忆是知识向量、图谱、原始文档与元数据。会话结束后完整流水脱敏归档，任何一次历史会话都可被完整查询。

边界的判据是**信息的生命周期与权威来源**，不是存储技术。新增一类信息时先问它活多久、谁是权威来源，再决定放哪层。

**Blocked by:** risk-monitoring-agent #05 — 风控专员自然语言查询

**Status:** implemented

- [x] 三层边界有明确定义与判据，新增一类信息时能据此决定归属
- [x] 短期记忆滑动过期，总 token 超预算时截断最旧消息
- [x] 超长对话（远超 token 预算）不报错，最旧消息被截断而最新消息保留
- [x] 会话不跨登录延续
- [x] 中期记忆：画像走 Cache-Aside，工单直接查库、热点可缓存
- [x] 会话结束后完整流水写入归档，**写入前脱敏**身份证号、手机号、真实姓名、银行卡号
- [x] 工具调用记录随归档留存
- [x] 可按会话标识或用户标识查询历史会话
