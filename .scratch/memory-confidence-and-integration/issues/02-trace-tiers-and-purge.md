# 02 — 留痕分级与清理

**What to build:** 留痕分两级：审计级（使用者、Agent、问题、最终答案、引用文档、内容分类）永久保存；调试级（完整提示词、原始检索片段、token 与耗时明细）保留一段时间后删除。清理任务接受一个明确的时间基准参数。

时间基准这条看起来是小细节，但如果清理任务在内部读当前时间，那么「保留期外的记录被删除」就只能靠等待真实时间流逝或改系统时钟来验证——实际上等于测不了（ADR-0011）。

**Blocked by:** 01 — 三层记忆边界与归档脱敏

**Status:** implemented

- [x] 审计级留痕永久保存，不受任何清理影响
- [x] 调试级留痕在保留期后被删除
- [x] **清理任务的时间基准由参数传入，不在内部读时钟**
- [x] 测试可断言「基准为某时刻时，恰好这几条被删、那几条还在」
- [x] 生产调用方在最外层取一次当前时间传入，保证一次批处理内所有记录用同一基准
- [x] 清理可手工触发
