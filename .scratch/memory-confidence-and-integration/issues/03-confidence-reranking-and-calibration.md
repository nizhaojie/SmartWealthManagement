# 03 — 置信度综合重排与周期校准

**What to build:** 同一批记忆单元在不同场景下的排序不同——做产品推荐时语义相似度权重最高，做风险研判时时效性权重最高。另有周期任务定期重算全量置信度并把过期标签标记为已过期，于是一年前的画像标签会显示比上周的标签更低的可信度。

**Blocked by:** 02 — 留痕分级与清理

**Status:** implemented

- [x] 五因子加权重排：语义相似度、时效性、历史准确率、基础置信分、冲突惩罚
- [x] 权重按场景配置，不硬编码；不同场景配置产生不同排序
- [x] **重排的输出是排序，不是过滤**——低分单元排在后面不被丢弃，丢弃的判断留给调用方
- [x] 重排实现为纯函数，可直接测输入输出
- [x] 周期任务重算全量置信度并标记过期标签
- [x] 校准同样接受明确的时间基准参数（ADR-0011）
- [x] 校准可手工触发
- [x] 画像面板渲染标签经时间衰减后的置信度
