# 04 — Agent 间事件协作

**What to build:** 风控刚对一位客户发出重度预警，顾问为他生成方案时就看到风险标记；客服察觉到客户在反复打听转账限额，风控那边收到关注提示。发布方不知道订阅方是谁，订阅方处理失败也不会拖垮发布方。

**Blocked by:** 03 — 置信度综合重排与周期校准

**Status:** implemented

- [x] 事件载荷结构明确定义：事件类型、来源、载荷、时间戳、追踪标识
- [x] **发布方不关心有几个订阅方**，新增订阅不需要改发布方
- [x] **订阅方处理失败不影响发布方**——协作是增强，核心链路不依赖它
- [x] 风控预警广播后，投顾为该客户生成的内容带风险标记
- [x] 客服识别到高风险意图后通知风控关注
- [x] 订阅方抛错时发布方的请求仍然成功
- [x] 事件总线不可用时核心链路继续，仅记录日志
