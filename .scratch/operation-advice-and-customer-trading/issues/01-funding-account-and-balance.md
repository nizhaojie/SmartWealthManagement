# 01 — 资金账户与可用余额

**What to build:** 客户在本机构的可用资金有了载体：一个客户一个资金账户、一个可用余额字段。余额与画像里的总资产是两个概念——总资产是客户在所有地方的资产规模，余额只装客户能在这里动用的钱。

**Blocked by:** 无前置（`foundation-and-customer-service-slice` 的建表与迁移已就绪）

**Status:** implemented

- [x] 资金账户表与迁移：一个客户一个账户（唯一约束）
- [x] 可用余额字段，精度与 `fin_transaction.amount` 一致
- [x] 客户侧只读接口：取本人余额；**客户标识由身份推导，不接受请求体传入**
- [x] 内部侧只读接口：客户经理只能看名下客户的余额（复用 `app/customer_scope.py`）
- [x] 种子：给每位客户一个初始余额，**给足**（演示需要反复扣款）；同时**刻意留一位余额很少的客户**，用于演示「余额不足被拒绝」
- [x] 余额与画像 `total_assets` 不共用字段、不互相写
- [x] 断言：客户 A 的凭证取不到客户 B 的余额
