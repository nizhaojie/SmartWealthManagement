# 01 — 产品筛选与固定排序

**What to build:** 客户按客观要素筛选产品，拿到一份符合条件的清单。清单按产品代码排序，页面上常驻一句「这是符合条件的产品清单，不是推荐」，并提供「请顾问出具方案」入口。越级产品不在清单里。这个 ticket 刻意让列表变得不那么「好用」——不能按收益率排序，理由见 ADR-0005。

**Blocked by:** customer-profiling-and-suitability #04 — 内部端客户画像面板

**Status:** implemented

- [x] 筛选条件只含客观已披露要素：产品类型、风险等级、期限、起投金额、业绩基准
- [x] **排序键在服务端写死为产品代码，不接受客户端传入**
- [x] **护栏测试：传入任何排序参数都不改变返回顺序**
- [x] **护栏测试：前端产品表格不渲染任何可排序表头**
- [x] 清单中不出现超出客户风险承受等级的产品
- [x] 「这不是推荐」的说明常驻，结果为 1 条、2 条、20 条时都渲染
- [x] 「请顾问出具方案」入口存在且可点击
- [x] 产品详情可查看完整已披露要素
- [x] 筛选无结果时提示条件过严并给出放宽建议
