# 02 — 方案请求的提交与状态查看

**What to build:** 客户点「请顾问出具方案」后产生一条请求，他能看到这条请求现在是什么状态——顾问有没有在处理。请求进入理财顾问的待办范围，但方案内容的生成与审核不在本 ticket。

**Blocked by:** 01 — 产品筛选与固定排序

**Status:** implemented

- [x] 提交请求后客户可看到该请求及其状态
- [x] 请求记录客户、提交时间与触发它的筛选条件
- [x] 客户只能看到自己提交的请求
- [x] 请求在内部侧可被列出（供后续审核队列消费）
- [x] 重复提交同一条件的请求有合理处理，不产生大量重复待办
