# 03 — 客户端资产页：持仓与交易流水

**What to build:** 客户打开资产页，一眼看到持仓总市值、持仓只数与自己的风险承受等级，下面是持仓明细与交易流水，流水可按时间与类型筛选。还没买任何东西的客户看到友好的空状态而不是空白表格。

**Blocked by:** 02 — 方案请求的提交与状态查看

**Status:** ready-for-agent

- [ ] 持仓明细展示产品、份额、成本、市值、盈亏
- [ ] 总市值与持仓只数由服务端聚合给出，客户不必自己加
- [ ] 风险承受等级结论可见
- [ ] 交易流水可按时间范围与交易类型筛选
- [ ] **客户只能看到自己的持仓与交易**
- [ ] **客户标识由服务端从身份推导，不接受请求体传入**；伪造他人标识时返回本人数据或被拒绝
- [ ] 无持仓时渲染空状态
- [ ] 落在客户端应用内，有独立路由
