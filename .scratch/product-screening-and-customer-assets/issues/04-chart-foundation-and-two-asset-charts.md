# 04 — 图表基座与两张资产图

**What to build:** 客户在资产页看到两张图：钱实际分布在哪几类资产上，以及持仓按产品风险等级的分布。同时建立整个项目的图表基座——图表壳与一套经过对比度校验的分类色板，后续三张图都长在它上面。

**Blocked by:** 03 — 客户端资产页：持仓与交易流水

**Status:** implemented

- [x] 图表壳放在共享包中，只承载壳与主题，不含业务语义（ADR-0003）
- [x] **分类色板与 UI 主色分开定义**：UI 主色是单一色相，分类数据需要色相拉开
- [x] **色板经过对比度校验，不靠肉眼挑选**——本团队曾因单色化导致图表系列失去辨识度而返工
- [x] 实际配置图用饼图或环图，数据**由持仓聚合得出**，不读画像里的目标配置（ADR-0006）
- [x] 风险等级分布图用横向条形图，**类别按 R1 到 R5 固定顺序排列，不按数值大小重排**
- [x] 两张图共用同一套封装
- [x] 空数据时渲染空状态，图表区域不留空白
- [x] 加载态有显式设计
- [x] 测试断言数据到图表配置的映射（类别顺序、系列数量、空数据处理），不断言像素输出
