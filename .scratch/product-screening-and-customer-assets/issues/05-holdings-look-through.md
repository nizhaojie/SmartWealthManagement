# 05 — 持仓穿透

**What to build:** 客户把一笔持仓逐层展开，看到自己实际间接持有了什么底层资产——五只基金可能都重仓同一个行业，穿透之后这件事才看得见。

**Blocked by:** 04 — 图表基座与两张资产图

**Status:** implemented

- [x] 沿产品的底层持有关系逐层展开到底层资产
- [x] 用数据库递归查询实现，不在应用层写循环拉取（ADR-0002）
- [x] **持有关系成环时查询有深度上限并报出异常，不挂死**
- [x] 穿透结果按底层资产聚合，同一底层资产的多条路径合并
- [x] 界面上可逐层展开与收起
- [x] 测试数据中包含至少两层嵌套的产品，以及一组成环数据用于验证有界终止
