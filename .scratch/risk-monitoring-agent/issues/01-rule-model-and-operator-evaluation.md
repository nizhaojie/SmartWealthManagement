# 01 — 规则数据模型与算子求值

**What to build:** 20 条反洗钱可疑交易识别规则存在库里而不是硬编码，每条可单独启停，调整阈值不需要改代码。求值由代码中一组有限且封闭的算子完成——大于、小于、区间、计数、时间窗内聚合等。

**阈值判断不经过模型。** 「这笔交易是否超过五万元」是确定性的数值比较，交给模型就变成一次概率性推断，比较错一次就是一次漏报。

**Blocked by:** knowledge-graph-and-graphrag #04 — 图谱关系图界面

**Status:** ready-for-agent

- [ ] 规则存库：字段、运算符、阈值、预警等级、权重
- [ ] **算子集合有限且封闭**——规则数据无法表达任意逻辑，否则它就是存在数据库里的代码，既不可测也不可审
- [ ] 20 条规则覆盖大额交易、同日累计、频繁交易、快进快出等场景
- [ ] 每条规则可单独启停；停用后不再参与匹配
- [ ] 阈值可调整且调整有记录
- [ ] **求值实现为纯函数**：输入一笔交易与一条规则，输出是否命中
- [ ] 每条规则的边界值各测一次：恰好等于阈值、刚好低于阈值
- [ ] **求值链路任何环节不经过模型**
