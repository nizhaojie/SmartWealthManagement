# 03 — 工单派生与处置流程

**What to build:** 风控专员从一条预警派生工单，工单有受理人、状态与处置结论；每次状态流转都必须填写理由。工单也能来自预警之外的源头，比如客户投诉或转人工。任何预警的关闭都由人做出并留下理由，系统不自动关闭。

**Blocked by:** 02 — 交易事件落库广播与预警分级

**Status:** ready-for-agent

- [ ] 工单有受理人、状态与处置结论，生命周期为待处理 → 处理中 → 已完成 | 已关闭
- [ ] **一条预警最多派生一张工单**，重复派生被拒绝
- [ ] 工单可来自预警之外的源头（客户投诉、转人工）
- [ ] **每次状态流转记录处置人与非空理由**，理由为空的流转请求被拒绝
- [ ] 预警可被判定为已排除并说明原因，也可被升级
- [ ] **系统不自动关闭任何预警**
- [ ] 风控专员以外的角色调用处置接口被拒绝
