# 04 — 预警与工单界面

**What to build:** 风控专员打开预警列表，按等级筛出需要先看的；点进详情看到触发了哪些规则、每条规则的具体依据（哪个字段、什么值、超过了什么阈值）、关联交易与客户、以及这位客户的历史预警。判断完派生工单并填写处置理由。

命中依据要到字段与值的粒度——「金额 520000 ≥ 阈值 500000」，而不只是「命中大额交易规则」。风控专员靠这个判断误报。

**Blocked by:** 03 — 工单派生与处置流程

**Status:** ready-for-agent

- [ ] 预警列表可按等级、状态、时间筛选
- [ ] 预警详情页有独立 URL
- [ ] **命中依据展示到字段与值的粒度**
- [ ] 详情展示关联交易与客户信息，不必切换页面
- [ ] 展示该客户的历史预警记录
- [ ] 展示预警的置信度，可据此排序
- [ ] 派生工单入口；处置表单的理由必填，为空无法提交
- [ ] 工单列表及其状态可查看
- [ ] 无预警时渲染空状态
- [ ] 理财顾问与客户经理能看到自己负责客户的预警状态
- [ ] 落在内部工作台既有外壳内
