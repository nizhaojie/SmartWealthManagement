# 04 — 规则管理界面

**What to build:** `RiskRulesTab` 从「只读列表 + 启停开关 + 阈值对话框」长成一个规则编辑器：新建与编辑走同一个对话框（判定口径只读）、删除与启停都要收理由、已删除的规则可筛选可见、变更记录有地方可看。

**Blocked by:** `risk-rule-management` #03 — 创建、修改、删除接口与留痕扩展

**Status:** ready-for-agent

- [ ] 「新建规则」按钮 → 对话框：分类 → 字段 → 算子 → 阈值四步联动，选项与允许组合全部来自 `GET /schema`
- [ ] 选完字段后算子下拉只剩该字段允许的那几个；阈值输入框的数量与键名随算子的 `threshold_keys` 变化（`gte` 一个、`between` 两个）
- [ ] `window_hours` 只在时间窗算子出现；其余算子不出现
- [ ] 新建对话框带「创建理由」（必填）
- [ ] 新建成功提示必须包含「**新规则从下一笔交易起生效，历史交易不会被重新判定**」
- [ ] 「编辑」按钮 → 同一对话框：编号只读，判定形状与阈值四项控件只读，并附一句「要改判定形状请删除后重建，要改阈值请用『调整阈值』」
- [ ] 「删除」→ `ElMessageBox.prompt` 收理由（`inputValidator` 强制非空，错误就地提示）
- [ ] 启停开关改为「点一下先弹理由」，与删除同一范式
- [ ] 「显示已删除」筛选（默认关，服务端参数 `include_deleted`）；已删行置灰、只读、不留编辑与启停控件
- [ ] 「查看变更记录」→ 只读对话框，渲染 `GET /{id}/changes`（**这个接口此前没有前端入口**）；已删行也要能打开它
- [ ] 非风控专员：三个写按钮与开关一律不出现或禁用，沿用既有的只读提示文案
- [ ] 组件测试：算子下拉随字段收敛、阈值输入随算子变形、编辑态判定口径只读、删除理由为空无法提交、已删行无编辑控件

**一处会被忽略的细节：** `include_deleted` 必须是服务端参数。前端拿到当前页再过滤，会让「共 N 条」与实际行数对不上——那正是 `RiskRulesTab.vue:99-101` 那条注释在解释的问题。
