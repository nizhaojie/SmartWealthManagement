# 目标配置与实际配置是两个概念

需求文档的 `fin_customer_profile.asset_allocation` 字段注释写的是「资产配置偏好」，但客户实际持有的配置要从持仓聚合得出，那是另一个数字。文档只给了一个名字，本项目拆成**目标配置**（意愿，来自画像）与**实际配置**（事实，来自持仓聚合）两个术语。

## Consequences

两者的差额本身就是投顾工作的对象——「你想要 30% 股票，实际持有 55%」正是理财顾问要和客户谈的事，也正是「资产配置建议」这个功能存在的意义。如果只保留一个概念，这个信息就消失了，投顾工作台上的配置建议会变成无源之水。

落到界面：客户端「我的资产」页画实际配置；内部端客户画像面板画两者对比。对比用成对横向条形而不是双饼图——两个饼图之间人眼无法比较扇区大小，条形可以对齐直读差值。
