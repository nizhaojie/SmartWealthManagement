# 留痕清理与周期校准接受明确的时间基准，不在内部读当前时间

调试级留痕的清理任务与置信度的周期校准任务，都把「现在是什么时候」作为参数传入，而不是在函数内部读取系统时钟。

## Consequences

任何读者的默认写法都是在内部取当前时间，所以这条记下来，避免后来者把它「修掉」。

理由是可测性：如果内部读时钟，那么「保留期外的记录被删除、保留期内的不动」这个行为就只能靠等待真实时间流逝，或者改动系统时钟来验证——前者不现实，后者会污染整个测试进程。参数化之后，一个用例可以直接断言「基准为某时刻时，恰好这几条被删、那几条还在」。

置信度的时间衰减同理：标签的存在天数由传入基准与创建时间相减得出，于是「一年前的标签衰减后是多少」成为一个可以直接断言的纯计算。

生产调用方在最外层取一次当前时间传进去，这也顺带保证了一次批处理内部所有记录用的是同一个时间基准，不会因为任务跑了几分钟而出现前后不一致。
